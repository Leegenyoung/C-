# 실습과제1
```
16MB 메모리의 주소의 범위를 구하시오
```
- 주소 범위: 0x000000 ~ 0xFFFFFF
```
변수의 주소를 설명하시오
```
- 변수가 저장된 메모리 공간의 시작 번지(위치)
```
변수의 주소의 자료형은 무엇인가
```
- 포인터형 (int*, char*, double* 등)
```
포인터란 무엇인가
```
- 메모리 주소를 저장하는 변수
```
포인터의 자료형은 무엇인가
```
- 자료형* 형태 (int*, char*, double* ...등), 가리키는 변수의 타입에 따라 결정됨
```
변수의 주소를 int형 변수에 저장하면 어떻게 되는가
```
- 64비트 시스템에서 주소는 8바이트, int는 4바이트 → 주소 잘림(데이터 손실) 발생해, 포인터 연산 불가

# 실습과제2
```
다음에서 pt가 가리키는 데이터의 자료형은 무엇인가
```
- double
```
다음에서 pt에 저장될 주소의 자료형은 무엇인가
```
- double형 변수의 주소
```
다음에서 pt의 자료형은 무엇인가
```
- double * (double형 포인터)
```
다음 처럼 포인터를 선언할 때 double의 의미를 설명하라
```
- pt가 double형 변수를 가리키는 포인터임을 명시한다. 즉, *pt로 역참조했을 때 double 크기(8바이트)만큼 읽어오겠다는 타입 정보를 컴파일러에 알려주는 역할이다.
```
포인터 변수 pt가 메모리에 할당될 때 메모리 크기
```
- 포인터 변수는 주소값을 저장하므로, double과 무관하게 시스템의 주소 크기에 따라 결정된다.

# 실습과제4
# 소스코드 설명
#include <stdio.h>
```
- printf 등 입출력 함수의 선언을 포함하고 있는 헤더파일 stdio.h를 포함
```
int main(void)
```
- 메인함수 시작
```
char   a = 'A';
```
- 문자 1개를 저장하는 char형 변수 a를 선언하고 문자 'A'로 초기화
```
int    b = 36;
```
- 정수를 저장하는 int형 변수 b를 선언하고 정수 36으로 초기화
```
double c = 3.141592;
```
- 실수를 저장하는 double형 변수 c를 선언하고 실수 3.141592로 초기화
```
printf("char형 변수 a의 주소 : %p\n", (void *)&a);
```
- &a로 변수 a의 메모리 주소를 가져오고, (void *)로 포인터 타입을 통일한 뒤, %p 형식 지정자로 주소값을 16진수로 출력, \n으로 줄바꿈
```
printf("int형 변수 b의 주소 : %p\n",  (void *)&b);
```
- 위와 동일하게 int형 변수 b의 메모리 주소를 %p로 출력
```
printf("double형 변수 c의 주소 : %p\n", (void *)&c);
```
- 위와 동일하게 double형 변수 c의 메모리 주소를 %p로 출력
```
return 0;
```
- 0을 반환하고 메인함수 정상 종료
